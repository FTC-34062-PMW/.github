## Use the right repository


- **Robot software:** implementation, hardware configuration, autonomous routines, and TeleOp.
- **Simulator:** simulation code, reproducible scenarios, and validation tooling.
- **This repository:** public team presentation and reusable collaboration conventions.


Open implementation issues in the repository that owns the code. Keep internal strategy, detailed robot designs, private links, and team-only records in the appropriate private repository.


## Template behavior


GitHub can use community health files from this public `.github` repository as defaults where a repository has no applicable local override. A local template or contribution guide takes precedence; check the target repository's issue chooser and PR form before relying on inheritance. Workflows, labels, and branch rules are not inherited from this repository.


## Maintenance


Keep all GitHub documentation and collaboration content in English. Review the playbook when the development workflow changes, and keep season-specific setup commands in each code repository rather than duplicating them here.
